# Docs Scope

Docs Scope is a website indexing engine that crawls documentation websites and blogs, extracts their content, and builds a searchable knowledge base.

The project focuses on information retrieval and search rather than simply wrapping an LLM. It combines concurrent web crawling, content extraction, full-text search, semantic search, and AI-assisted question answering into a single system.

## Planned Features

- Crawl documentation websites
- Concurrent page downloading
- Content extraction
- Full-text search
- Semantic search using embeddings
- AI-assisted Q&A with citations
- Crawl progress dashboard

## Tech Stack

### Backend
- FastAPI
- PostgreSQL

### Frontend
- Vue

### AI
- Embeddings
- Retrieval-Augmented Generation (RAG)
